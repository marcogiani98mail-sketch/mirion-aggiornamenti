# Gli aggiornamenti di Mirion

Qui ci sono solo gli installatori di Mirion, firmati, una release per versione. Le Mirion installate leggono `releases/latest/download/aggiornamento.json` e, se c'è una versione nuova, la propongono («C'è Mirion… Aggiorna»): installano solo un file con la firma giusta e l'impronta che corrisponde.

Il codice di Mirion non è qui: sta in un repository privato.
